THE DAILY CUP — WEBSITE
=======================

OPEN: Double-click index.html to preview.
PUBLISH: Upload all files and the assets/ folder together to your static web host.

EDITING
- index.html: Site title, content, prices, contact email, and awards.
- styles.css: Design and responsive layout.
- script.js: Mobile menu and copyright year.
- assets/: Logo and promotional image.

AWARDS — EASY EDITING
Open index.html and search for: id="awards-list"
Each award is an <article class="award-card"> with a <h3> title.
Change the title to rename an award, duplicate an article to add one,
or delete an article to remove one. No code changes elsewhere are needed.
